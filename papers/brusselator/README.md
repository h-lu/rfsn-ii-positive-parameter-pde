# Brusselator companion paper

This directory contains the independently buildable source for
*Localized Stationary Profiles in a Singular Diffusion Limit of the
Brusselator*.

Build from this directory with:

```text
make
```

The paper proves the positive-parameter analytic continuation relative to
the explicitly stated computer-assisted Core Lemma. The final submission
package still requires a stable public archive of that lemma's complete
evidence closure.
