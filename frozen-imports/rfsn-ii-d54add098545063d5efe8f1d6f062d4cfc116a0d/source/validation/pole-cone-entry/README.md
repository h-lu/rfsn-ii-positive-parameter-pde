# Validated raw-crest entry into the limiting pole cone

> **Certificate status: PASS.**
>
> This certificate concerns only the limiting core \(\lambda=0\), the
> exact raw-crest curve \(a=0\), and \(r\in[1/20,2]\). It proves neither a
> positive-parameter seam nor a physical touchdown.

## 1. Certified statement

For

\[
 U'=P,\qquad P'=-U^2-V,\qquad V'=Q,\qquad Q'=U,
\]

put

\[
 x=-U,\qquad y=-P,\qquad q=-Q,\qquad w=-V.
\]

Every orbit issued from

\[
 (x,y,q,w)(0)=(-2r,0,0,r^2),\qquad
 r\in[1/20,2],                                            \tag{1.1}
\]

has a validated increasing first hit of \(x=20\). At that event the
complete parameter family is enclosed by

\[
 \begin{aligned}
 \tau_{20}&\in[2.6521607865816179,\ 5.912365345922618],\\
 y&\in[60.695614590291292,\ 86.040960525494896],\\
 q&\in[5.0457054657276323,\ 9.7080397535672063],\\
 w&\in[-0.57015991592634063,\ 5.2894291785056833].
                                                               \tag{1.2}
 \end{aligned}
\]

For \(\theta=1/2\), define

\[
 D=\frac12x^2-w,\qquad H=xy-q.                            \tag{1.3}
\]

The certificate gives

\[
 D\ge194.7105708214942,\qquad
 H\ge1204.204252052258.                                  \tag{1.4}
\]

Thus every orbit in (1.1) enters the analytic invariant cone

\[
 \mathcal K=\{x\ge20,\ y>0,\ q\ge0,\ D\ge0,\ H\ge0\}.    \tag{1.5}
\]

The parameter interval corresponds to

\[
 \mathcal E_0=-\frac43r^3
 \in[-32/3,-1/6000].
\]

## 2. Analytic tail after the validated bridge

Inside (1.5),

\[
 y'\ge\frac12x^2,\qquad D'=H,
\]

and

\[
 H'=y^2+x(x^2-w)-x
 \ge y^2+\frac12x^3-x>0.                                \tag{2.1}
\]

At \(x=20\), the last two terms in (2.1) already have the certified
lower bound \(3980\). Hence the cone is forward invariant. Moreover,

\[
 y^2(x)\ge y(20)^2+\frac{x^3-20^3}{3}
           >\frac{x^3}{3}.                               \tag{2.2}
\]

The remaining lifetime is bounded by

\[
 \int_{20}^{\infty}\frac{dx}{y(x)}
 <\int_{20}^{\infty}\sqrt3\,x^{-3/2}\,dx
 =\sqrt{\frac35}.                                       \tag{2.3}
\]

Consequently all certified raw-crest orbits have a finite pole before

\[
 t_b<5.912365345922618+\sqrt{3/5}<6.687.                 \tag{2.4}
\]

The analytic asymptotics are proved in
[the universal pole-channel theorem](../../archive/research-history/papers/paper-a/UNIVERSAL_CORE_POLE_CHANNEL.md).

## 3. Finite cover and interval representation

The source partitions \([1/20,2]\) into the 1950 closed boxes

\[
 [i/1000,(i+1)/1000],\qquad i=50,\ldots,1999.            \tag{3.1}
\]

The endpoint strings are generated by integer quotient and remainder, so
adjacent boxes share byte-identical decimal endpoints. CAPD constructs
intervals from those decimal strings with outward rounding.

On a box write \(r=m+s\). The exact source curve is enclosed as

\[
 (-2r,0,0,r^2)
 =(-2m,0,0,m^2)+(-2,0,0,2m)s+(0,0,0,s^2).              \tag{3.2}
\]

The last term is enclosed by a second interval generator. This retains the
dominant \(x\)-\(w\) correlation; the remaining loss of correlation is
outward and therefore safe.

For each box the program performs:

1. a C0HOTripletonSet integration to the increasing Poincare section
   \(x=20\);
2. strict tests of the time, \(y,q,D,H\), and inward-vector-field margins;
3. a C1HORect2Set integration of the same enclosure;
4. multiplication of the ambient monodromy by the exact source tangent
   \((-2,0,0,2r)\);
5. an explicit event-time correction and strict C1 margin tests.

Any C0, C1 or CAPD exception exits with code 10, 11 or 12. PASS is printed
only after every box succeeds.

## 4. C1 boundary

The auxiliary C1 certificate gives

\[
 \partial_r\tau_{20}
 \in[-36.27852837487999,-0.35893273545782034],
\]

and a common componentwise event-map derivative bound below
\(9878.456\). This proves finite-event C1 control only. It does not prove
differentiability of the blow-up time \(t_b(r)\), a stable phase at the
compactified pole, or second/third parameter jets.

The validation pins CAPD 6.1.0 at commit
731079217a9254ea2948d742df2b170895effe7f, uses FILIB intervals, and was

~~~bash

  -DCAPD_INTERVAL_TYPE=FILIB \
  -DCAPD_ENABLE_MULTIPRECISION=OFF \
  -DCAPD_BUILD_TESTS=OFF \
  -DCAPD_BUILD_EXAMPLES=OFF
cmake --build CAPD/build -j

g++ cone_entry_certificate.cpp \
  $(CAPD/build/bin/capd-config --cflags) \
  $(CAPD/build/bin/capd-config --libs) \
  -o cone_entry_certificate

./cone_entry_certificate
~~~

The recorded PASS output is
[certificate.json](certificate.json). Rebuilding directly from the
repository source reproduced all interval endpoints exactly on the audited
machine; wall time was 9--14 seconds and peak resident memory about 6 MB.

## 6. Scope exclusions

This certificate does not prove:

- cone entry outside \(r\in[1/20,2]\);
- a common stable phase or parameter jets at the pole;
- persistence for \(\lambda>0\);
- continuation through a physical coordinate singularity;
- identification with a touchdown or the algebraic \(K_1\) channel;
- return H4, two-half incidence, or a periodic orbit.

Those exclusions are theorem boundaries, not caveats to the validated
limiting-core result.
