# P2e direct-source shooting design audit

**Status:** `COMPUTED_INTERVAL_DESIGN_NONCLAIM`. No P2e atom is passed by
this report, and the generated predictor table is not frozen for a full run.

## Object actually computed

For a fixed direct P2bK source phase
\(\phi\in\{\phi_a^0,2\pi\}\), the design kernel seeks, for every parameter
\(\mu=(r,a_2,\epsilon)\), an inner phase \(\vartheta_\mu\) such that the true
local unstable-graph orbit starting at expanding radius \(10^{-6}\) has its
first outward hit of radius \(10^{-2}\) at direct Kato phase
\(\phi+2\pi\). The kernel is
[`design/p2e_source_trace_shoot_scout.cpp`](design/p2e_source_trace_shoot_scout.cpp);
its floating chart candidates are generated by
[`design/p2e_source_trace_predictors.py`](design/p2e_source_trace_predictors.py).

The generator is explicitly non-evidentiary: it integrates the centre orbit
with \(s_1=s_2=0\), while the interval kernel encloses the unknown true graph.
The calculation tightens the value of the canonical direct source point
already defined by `P2.KATO.SOURCE_PARAMETERIZATION`; it does not replace
that parameterization.

## Correct first-hit formulation

An earlier prototype stopped on a fixed phase section and then solved for
radius \(10^{-2}\). That could not exclude an earlier radius hit followed by a
return. It has been discarded. The current kernel instead takes the CAPD
Poincaré section

\[
  \ell=\log(10^{-2})
\]

with `MinusPlus` direction and exactly one crossing, and solves

\[
  G_\mu(\vartheta)
  =\theta_{\mathrm{first\ radius\ hit}}(\vartheta)-\phi-2\pi=0
\]

by scalar interval Newton. The true graph starts strictly inside the physical
face. On the P2a local graph,
\(\lVert H_\mu(u)\rVert\le \lVert u\rVert^2/4\), and the implemented polar
estimate gives

\[
  \frac{d\ell}{dt}\ge\alpha-\mathcal E>0,
  \qquad
  \frac{d\theta}{dt}\ge\beta-\mathcal E>0
\]

up to the first outer hit. Evaluation of the nonlinear ratio at
\(\rho=10^{-2}\) is valid because both
\(\rho(1+\rho/4)^2\) and
\(\rho^2(1+\rho/4)^3\) increase for \(\rho>0\). Thus the CAPD event is the
unique first outward radius hit, while phase monotonicity fixes the lift. The
numerical window \(10<t<16\) is only a branch diagnostic.

## Exact leaf design and quantifiers

The exact design leaves are

\[
 [i/3200,(i+1)/3200]\times
 [(j-64)/256,(j-63)/256]\times
 [(k+8)/10,(k+9)/10],
\]

where \(0\le i<64\), \(0\le j<128\), and \(0\le k<4\). Eight consecutive
\(r\)-leaves make one original bridge cell.

For each final parameter \(\mu\), let \(s_*\) be the actual graph value at the
unknown inner phase. The centre-parameter map encloses every admissible
\(\lVert s_*\rVert\le10^{-12}/4\). In the mean-value comparison, \(s_*\) is
held fixed along the artificial segment from the cell centre to \(\mu\), so
no \(D_\mu H\) term belongs in that numerator. The Newton denominator
separately includes the graph tangent through
\(\lVert DH_\mu\rVert\le1\).

One invocation proves at most one refined leaf. A claim-bearing cover would
still need all leaves and common-face root identification; local interval
passes cannot simply be counted as a global trace.

## Design evidence obtained

The floating ALG predictor generation produced exactly 32,768 unique
Cartesian keys. Its largest centre residual was
\(5.51\times10^{-14}\). A disclosed 144-leaf strict design sample crossed
twelve radial indices, both sides and both extrema of the \(a_2\) axis, and
both epsilon extrema. All 144 leaves passed. On the high-\(r\),
extreme-negative-\(a_2\) leaf

\[
 [63/3200,1/50]\times[-1/4,-63/256]\times[11/10,6/5],
\]

the Newton image was approximately
\([-2.141,2.141]\times10^{-4}\), strictly inside
\([-4,4]\times10^{-4}\). These facts establish numerical feasibility only.

## Relation to the corrected P2e carrier

The phase-interface audit found that the former P2e structural file mixed the
P2d section phase \(\psi\) with aperture centers stated in the direct P2bK
phase \(\phi\).  Schema `/3` now displays `B.OUT` in the direct phase and
retains the exact P2d signed action by defining

\[
 E_{\rm out}^{\rm dir}(\phi,\nu)
 =E_{\rm out}^{\rm P2d}(\lambda_\mu(\phi),\nu),
\]

where the already proved orientation-preserving seam is

\[
  \phi=\kappa_\mu(\psi),\qquad \psi=\lambda_\mu(\phi).
\]

The P2d overlap proof explicitly states that \(\kappa_\mu\) is not assumed to
be a constant translation.  The raw unstable-graph shooting kernel computes
the \(\nu=0\) direct source spine; it does not compute
\(\lambda_\mu(\phi)\), the off-zero exact-action carrier, or the composition
above.  It therefore cannot certify `B.OUT` even though its displayed phase
now agrees with the direct phase used by the kernel.  Moreover P2bK already
proves the existence and regularity of that direct source circle, so a full
32,768-leaf raw shooting run would duplicate the spine while leaving the
actual seam and carrier open.

The P2d overlap and physical-slide proofs already imply that the finite
\(\kappa/\lambda\) seam exists with the needed regularity and that the
composed `B.OUT` is a \(C^2\) zero-energy embedding on the frozen action
collar.  A standalone numerical seam table would therefore duplicate a
qualitative conclusion rather than close the next atlas obligation.

The subsequent proof-bound axis-chart lemma now supplies an exact
zero-energy interval enclosure of the true \(\nu=0\) source:
\(s_1=H_{10,1}(u)+\eta\), \(|\eta|<10^{-5}\), with \(s_2\) fixed by the
Hamiltonian and the true source confined by \(|\eta_\mu|\le5\times10^{-6}\).
It also proves that a complete strict zero-action event skeleton thickens to
some positive uniform exact-action subcollar.  Therefore the next
claim-bearing computation is the exterior ALG/POLE first-hit skeleton, with
HOM imported from P2c, not a full raw-source trace or a fixed-radius
off-axis evaluator.  Only interval wrapping of this enclosure would justify
reusing the direct-spine predictor locally.

The moving HOM target, residual \(+\)/\(-\) templates, proper phase arc,
physical carriers, incidence complex, first-event census, normalization, and
